A 30-day Facebook task plan · this website is its control panel

Short version: this site stores and shows a 30-day list of Facebook tasks. The Chrome extension shows the list to you. The AI agent (WebBrain) does the actual posting on Facebook, then ticks the task as done. Nothing is posted by this website itself.

The three parts (and what each one does)

They share one database. You only interact with the first two.

1

Chrome extension — “Daily Tasks”

The popup shows all 30 days with ✅ Done or ⏳ Pending and the prompt for each day. It is read-only: you cannot tick a task yourself, because only the AI is allowed to confirm a task was really completed on Facebook.

How to install it ↓
2

Task manager — this site, second page

Where you edit the plan: add a task, change its wording, delete one, or reset its status. Protected by your admin key. Opening it asks for that key once and remembers it in your browser.

Open the task manager →
3

AI agent — WebBrain + MCP

You paste DAILY_AGENT_PROMPT.md into the agent every day. It reads that day’s task, performs it on facebook.com with human-like timing, checks the result, and marks the task done. If it fails, the task stays pending.

See the raw task data →

How one day works

  1. You open the extension and look at today’s task, or the AI reads it from the API.
  2. The AI agent posts / comments / updates the Facebook page using WebBrain MCP.
  3. The AI verifies the result is visible, then calls PATCH /api/tasks/{day} with status: "done".
  4. You press Refresh in the extension popup — that day is now ✅ Done.

What the fields mean

These are the only columns stored for each of the 30 days.

FieldMeaning
DayThe day number of the plan, 1 to 30. Each day can exist only once.
TitleA short name for the task, e.g. “Update the profile bio”.
PromptThe instruction the AI agent follows, e.g. “Write and publish a post about organic farming”.
DetailsThe fine print: tone, length, rules, what counts as success.
Status⏳ Pending = not done yet. ✅ Done = the AI verified it on Facebook.
Completed by / atWho ticked it (normally ai_agent) and when.

What you need to do (once)

  1. Open the task manager with your admin key: /manage.html. Review or edit the 30 tasks.
  2. Install the extension: chrome://extensions → Developer mode → Load unpacked → select the project folder.
  3. Connect the popup: Settings tab → API base URL = this site’s address → Extension API key = the EXTENSION_API_KEY from Vercel.
  4. Connect WebBrain: Settings → General → Advanced → Cloud bridge → ws://127.0.0.1:17374/extension → enable.
  5. Each day: copy the prompt from DAILY_AGENT_PROMPT.md, fill in the day number, send it to the agent, then Refresh the popup.
Privacy: the database password lives only in Vercel’s environment variables. The Chrome extension stores only two things: this site’s URL and the extension API key. The admin key is kept in this browser’s local storage after you enter it.
