Daily prompt generator

Builds the full prompt for one day using the settings above. Save your settings first, then generate. Paste the result into your AI agent (WebBrain MCP).

The prompt is generated by GET /api/agent-prompt?day=N from the saved settings and the task text. If you tick “Insert my extension key”, the placeholder is replaced in your browser only — the key is never stored in MongoDB.
