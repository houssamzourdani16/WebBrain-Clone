Connect to your API

Enter the Vercel deployment URL and the ADMIN_API_KEY. The key is stored only in this browser's localStorage and is sent as the X-Admin-Key header. MongoDB credentials are never used in the browser.

What this page is

This is the plan editor. It changes the list of 30 tasks that the Chrome extension shows and that the AI agent reads each day. It does not post to Facebook — the AI agent does that.

Add a task with + Add task, change its wording with Edit, or remove it with Delete. Each day number 1–30 can exist only once.

What each field and status means
  • Day — which day of the 30-day plan this task belongs to (1–30, unique).
  • Title — short name shown in the extension list.
  • Prompt — the exact instruction the AI follows on Facebook.
  • Details — the fine print: tone, length, rules, and what counts as success.
  • ⏳ Pending — not done yet. ✅ Done — the AI verified it on Facebook.
  • Completed by / at — who ticked it (normally ai_agent) and when.
